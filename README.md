# JS Algorithm Challenges

Coleccion personal de retos de logica y algoritmos resueltos en JavaScript.

## Estructura

```
/arrays        - Retos con arrays y matrices
/strings       - Manipulacion de cadenas
/objects       - Estructuras de datos con objetos
/sorting       - Algoritmos de ordenamiento
/recursion     - Problemas con recursividad
```

## Como usar

Cada archivo tiene el enunciado del reto en comentarios y la solucion debajo.

```bash
node arrays/two-sum.js
```

## Stack
- JavaScript (ES6+)
- Node.js
